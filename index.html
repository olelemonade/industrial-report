SCOPE 02受理 ≠ 发证

SCOPE 03目标 ≠ 结果

“2026 年量产交付”是企业计划，仍取决于取证、产品一致性、运营规则与配套基础设施。

SCOPE 04报道 ≠ 官宣

港股 IPO 仅见媒体报道；企业公开回应为专注研发与量产，未正式确认申报状态。

05 / Technology

核心技术与产品

企业强调四大核心技术领域的全栈自研、自主可控。近期商业化重心是分体式“陆地航母”，A868 则代表更高速、更长航程的下一产品方向。

Near-term flagship

陆地航母：
把飞行器装进车里

三轴六轮陆行体 + 可自动收纳的 X3-F 飞行体。产品逻辑不是让整车起飞，而是用地面母舰解决飞行器运输、补能与存放。

≈5 min一键自动分离 / 结合
6×6全轮驱动 + 后轮转向
>1,000 km陆行体 CLTC 综合续航
6×满油满电可为飞行体补能
800V SiC碳化硅增程平台
270°飞行体全景座舱

参数为企业产品页公开口径，实际续航与补能次数受工况影响。[3]

CORE 01

动力总成

双包冗余航空级动力电池，标称能量密度 255Wh/kg；六合一电推进系统标称体积扭矩密度 40Nm/L、推重比 12。

CORE 02

飞控导航

三余度飞控导航架构；单杆操纵降低学习门槛，提供手动与自动模式，可实现一键起飞、航线规划与自动飞行。

CORE 03

复合材料

碳纤维主体结构与桨叶，在航空器结构强度、重量和可折叠收纳尺寸之间取得平衡。

CORE 04

空中智能

多维环境融合感知、降落视野辅助和智能航线能力，把汽车领域的感知交互思路带入低空飞行。

单杆操纵 + 自动飞行

通过单一操纵杆集成起降、前后左右与转向控制，降低操作复杂度；自动模式仍应在法规、空域与系统边界内使用。

全域冗余安全架构

动力、飞控、供电、通信、操纵等关键系统配置备份。官方图示包括飞控导航三余度，动力能源、高低压供配电和操纵系统双余度。

07 / Judgment

商业化判断与风险

以下是基于公开事实形成的研究判断，不是企业承诺。低空经济的产业节奏由产品、监管、基础设施和用户接受度共同决定。

HIGH · GATE

适航与运行许可

TC、PC、单机适航及场景运行规则直接影响交付时间和可使用范围，是最关键的外部闸门。

HIGH · CONVERSION

订单转化与定价

公开订单能否转为交付、收入和回款，取决于证照、最终售价、使用场景、退款条款和融资方案。

MEDIUM · RAMP

规模质量与供应链

航空器需要比普通汽车更严格的一致性和可追溯体系，试产成功不等于产能已稳定释放。

MEDIUM · INFRA

营地、空域与补能

低空产品价值依赖起降点、空域协调、补能维护、气象服务等网络；基础设施不足会限制使用频率。

WATCH · USER

培训、保险与售后

大规模个人用户需要清晰的操作资质、训练体系、保险定价、定检维修和事故责任框架。

WATCH · CAPITAL

持续投入与资本节奏

研发、适航、建厂和生态建设均重资产。融资能力较强，但在收入规模化前仍需持续资本支持。
